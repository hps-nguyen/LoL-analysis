# League of Legends Win/Lose Analysis

This repository contains a redesigned GitHub Pages website for a League of Legends esports data analysis project.

The project was completed as a UC San Diego DSC 80 final project. DSC 80 focuses on the practice of data science: collecting and cleaning real-world datasets, performing exploratory analysis, assessing missingness, running hypothesis tests, building predictive models, and communicating findings clearly.

This analysis uses 2022 professional League of Legends match data from Oracle's Elixir to study which in-game factors are associated with winning and losing. The website presents the full project report, including exploratory data analysis, missingness assessment, hypothesis testing, prediction modeling, and fairness analysis.

Website content lives in `CONTENT.md`; the front end is implemented with static HTML, CSS, and JavaScript in `index.html` and `assets/`.
